# محمود اسلامک لائبریری — مصنف کی ویب سائٹ

اردو زبان میں اسلامی مصنف کی کتابوں، مضامین اور روزانہ حدیث گیلری کی سرکاری ویب سائٹ۔ خالص HTML/CSS/JavaScript سے بنائی گئی ہے — کسی بلڈ ٹول یا سرور کی ضرورت نہیں، براہِ راست GitHub Pages پر شائع کی جا سکتی ہے۔

## صفحات
- `index.html` — ہوم پیج (سلائیڈر، مصنف کا تعارف، کتابیں، مضامین، روزانہ حدیث، رابطہ، لوکیشن)
- `books.html` — تمام کتابیں (فلٹر + سرچ کے ساتھ)
- `articles.html` — تمام مضامین
- `article.html` — ایک مضمون کی مکمل تفصیل (`?id=article-1` جیسے پیرامیٹر سے)
- `hadith.html` — روزانہ حدیث گیلری (لائٹ باکس کے ساتھ)
- `contact.html` — رابطہ فارم اور نقشہ

## اپنا مواد شامل کریں
تمام کتابیں، مضامین اور حدیث کی تصاویر ایک ہی جگہ **`assets/js/data.js`** میں موجود ہیں۔ اس فائل کو کھول کر:
- کتاب کا نام، سرِ ورق کی تصویر، ڈاؤن لوڈ لنک اور آن لائن پڑھنے کا لنک تبدیل کریں (`SITE_BOOKS`)
- مضمون کا عنوان، خلاصہ اور مکمل متن شامل کریں (`SITE_ARTICLES`)
- روزانہ حدیث کی تصویر کا راستہ شامل کریں (`SITE_HADITH`)

نئی کتاب/مضمون شامل کرنے کے لیے بس موجودہ اندراج کاپی کر کے نئی تفصیلات بھر دیں — صفحات خودکار طور پر اپ ڈیٹ ہو جائیں گے۔

## فونٹس (اردو / عربی)
سائٹ **Jameel Noori Nastaleeq** (اردو) اور **Al Qalam Quran Majeed Web** (عربی) کے لیے تیار ہے۔ فونٹ فائلیں کاپی رائٹ کی وجہ سے شامل نہیں کی گئیں — تفصیلات کے لیے `assets/fonts/README.md` دیکھیں۔ فونٹ فائل شامل کیے بغیر بھی سائٹ Google Fonts کے متبادل (Noto Nastaliq Urdu / Amiri) کے ساتھ درست دکھائی دے گی۔

## تصاویر
`assets/images/` میں فی الحال نمائشی (placeholder) SVG تصاویر شامل ہیں — کتابوں کے سرِ ورق، حدیث کارڈز، ہیرو بینر اور مصنف کی تصویر کے لیے۔ اپنی اصل تصاویر انہی ناموں سے (یا نیا راستہ `data.js` میں لکھ کر) تبدیل کریں۔ بہترین نتائج کے لیے:
- کتاب کا سرِ ورق: 3:4.2 تناسب (مثلاً 800×1120px)
- حدیث کی تصویر: مربع تناسب 1:1 (مثلاً 1080×1080px)

## GitHub Pages پر شائع کرنا
1. یہ تمام فائلیں اپنے GitHub ریپوزیٹری میں اپ لوڈ کریں (فولڈر ڈھانچہ ویسے ہی رکھیں)۔
2. ریپوزیٹری کی **Settings → Pages** میں جائیں۔
3. **Branch** میں `main` (یا جو بھی برانچ استعمال ہو) اور فولڈر `/ (root)` منتخب کریں، پھر **Save** کریں۔
4. چند منٹ بعد سائٹ `https://username.github.io/repository-name/` پر دستیاب ہو جائے گی۔

## رابطہ فارم فعال کرنا
موجودہ فارم صرف نمائشی ہے (صفحہ ری لوڈ کیے بغیر پیغام بھیجتا ہے مگر کہیں محفوظ نہیں کرتا)۔ اسے حقیقی طور پر فعال کرنے کے لیے [Formspree](https://formspree.io) یا اسی طرح کی مفت سروس کا اکاؤنٹ بنا کر `index.html` اور `contact.html` میں موجود `<form data-contact-form>` کی `action` اور `method` خصوصیات شامل کریں۔
